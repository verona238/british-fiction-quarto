1 Введение и постановка задачи

В работе анализируется корпус A Small Collection of British Fiction (тексты и метаданные я брала из репозитория курса): 27 произведений 11 авторов конца XVIII—XIX веков. В описании корпуса указано 28 произведений — это расхождение в исходных метаданных, в самом файле overview строк 27. Цель — построить и интерпретировать модель атрибуции авторства, опираясь на лингвистические признаки и фреймворк {tidymodels}.

Особенность задачи

В корпусе 27 произведений, Эмили Бронте представлена одним романом «Грозовой перевал». При честной групповой кросс-валидации «один роман отложен» (leave-one-book-out) модель никогда не увидит примеров Эмили Бронте в обучении при предсказании ее романа и отнесет его к ближайшему стилистически автору.

Чтобы сделать сравнения статистически устойчивыми, я работаю не с целыми романами, а с чанками по 5000 слов.

4 Предобработка текстов

Тексты нужно очистить от шапок (заглавие/BY/имя автора/VOLUME/CHAPTER) и концевые маркеры (THE END).

Лемматизацию и стемминг я не делаю специально. Атрибуция авторства опирается на частоты служебных слов в их исходных формах, и нормализация словоформ только стерла бы авторский сигнал.

Код 
clean_one <- \(path) {
  raw <- readr::read_file(path)

  # Удаляю концевые маркеры только в самом конце, чтобы не зацепить
  # упоминания "the end" внутри прозы
  tail_chunk <- substr(raw, max(1, nchar(raw) - 500), nchar(raw))
  m <- regexpr("\\b(FINIS|THE END|End of the (Fourth|Fifth|Sixth|Project Gutenberg).*)\\b",
               tail_chunk, ignore.case = TRUE)
  if (m > 0) {
    cut_at <- nchar(raw) - 500 + m
    raw <- substr(raw, 1, cut_at - 1)
  }

  # Удаляю первые короткие строки шапки
  lines <- strsplit(raw, "\r?\n")[[1]]
  header_re <- "^\\s*(by|volume|chapter|book|preface|to the|dedication|a work by|nine volumes|one of|history)\\b"
  body_start <- 1L
  for (i in seq_len(min(25, length(lines)))) {
    L <- str_trim(lines[i])
    if (L == "") next
    if (nchar(L) < 40 && (toupper(L) == L || grepl(header_re, L, ignore.case = TRUE))) {
      body_start <- i + 1L; next
    }
    break
  }
  paste(lines[body_start:length(lines)], collapse = "\n")
}

texts <- files_df |>

5 Инжиниринг признаков

Я построила две группы признаков:

  1. MFW (200 самых частотных слов корпуса) — нормализованные частоты.
  2. Структурные признаки — средняя длина слова, средняя длина предложения, TTR, индекс Оноре, плотности запятой, точки с запятой, тире, восклицательных и вопросительных знаков.

Структурные признаки считаются на тех же чанках, что и MFW.

Частоты частей речи я не добавляла, чтобы не утяжелять пайплайн разбором через udpipe. 200 MFW и структурные метрики дают достаточный набор признаков для атрибуции.

Код 
MFW_N <- 200

# MFW
dfm_full  <- dfm(toks_chunks)
top_terms <- names(topfeatures(dfm_full, n = MFW_N))
dfm_mfw   <- dfm_full |>
  dfm_select(pattern = top_terms, selection = "keep") |>
  dfm_weight(scheme = "prop")
mfw_df <- dfm_mfw |>
  convert(to = "data.frame") |>
  as_tibble() |>
  rename_with(\(x) paste0("mfw_", x), -doc_id)

# Структурные признаки на тех же чанках
honore_r <- \(tw) {
  N <- length(tw); if (N == 0) return(NA_real_)
  tab <- table(tw); V <- length(tab); V1 <- sum(tab == 1)
  if (V1 == V) return(NA_real_)
  100 * log(N) / (1 - V1 / V)
}

chunk_substrings <- character(nrow(chunk_meta))
names(chunk_substrings) <- chunk_meta$doc_id

for (bk in unique(chunk_meta$book_id)) {
  text_raw <- texts$text[texts$file == bk]
  pos <- gregexpr("[A-Za-z][A-Za-z']*", text_raw, perl = TRUE)[[1]]
  match_lens <- attr(pos, "match.length")
  bk_chunks <- filter(chunk_meta, book_id == bk)
  for (i in seq_len(nrow(bk_chunks))) {
    chunk_n <- bk_chunks$n_tokens[i]
    word_start <- (i - 1) * CHUNK_SIZE + 1
    word_end   <- word_start + chunk_n - 1
    if (word_end > length(pos)) word_end <- length(pos)
    char_start <- pos[word_start]
    char_end   <- pos[word_end] + match_lens[word_end] - 1
    chunk_substrings[bk_chunks$doc_id[i]] <- substr(text_raw, char_start, char_end)
  }
}

struct_df <- tibble(
  doc_id  = chunk_meta$doc_id,
  mean_word_len = sapply(as.list(toks_chunks), \(w) mean(nchar(w))),
  ttr = sapply(as.list(toks_chunks), \(w) length(unique(w)) / length(w)),
  honore_r  = sapply(as.list(toks_chunks), honore_r),
  mean_sent_len = sapply(chunk_substrings[chunk_meta$doc_id], \(t) {
                    n_sent <- max(1, length(strsplit(t, "[.!?]+")[[1]]))
                    n_word <- length(strsplit(t, "\\s+")[[1]])
                    n_word / n_sent
                  }),
  comma_rate  = sapply(chunk_substrings[chunk_meta$doc_id],
                         \(t) 1000 * str_count(t, ",")  / nchar(t)),
  semicolon_rate = sapply(chunk_substrings[chunk_meta$doc_id],
                         \(t) 1000 * str_count(t, ";")  / nchar(t)),
  dash_rate = sapply(chunk_substrings[chunk_meta$doc_id],
                         \(t) 1000 * str_count(t, "--") / nchar(t)),
  question_rate = sapply(chunk_substrings[chunk_meta$doc_id],
                         \(t) 1000 * str_count(t, stringr::fixed("?")) / nchar(t)),
  excl_rate = sapply(chunk_substrings[chunk_meta$doc_id],
                         \(t) 1000 * str_count(t, stringr::fixed("!")) / nchar(t))
)

features <- chunk_meta |>
  left_join(mfw_df, by = "doc_id") |>
  left_join(struct_df, by = "doc_id") |>
  mutate(authorID = factor(authorID))

7.2 Рецепт и две модели

Код 
rec <- recipe(authorID ~ ., data = train_chunks) |>
  update_role(doc_id, book_id, author, n_tokens, new_role = "ID") |>
  step_zv(all_predictors()) |>
  step_normalize(all_numeric_predictors())

# Модель 1: мультиномиальная регрессия с L1/L2
multinom_spec <- multinom_reg(penalty = tune(), mixture = tune()) |>
  set_engine("glmnet") |>
  set_mode("classification")

# Модель 2: случайный лес
rf_spec <- rand_forest(trees = 500, mtry = tune(), min_n = tune()) |>
  set_engine("ranger", importance = "impurity") |>
  set_mode("classification")

wf_multinom <- workflow() |> 
  add_recipe(rec) |> 
  add_model(multinom_spec)
wf_rf <- workflow() |> 
  add_recipe(rec) |> 
  add_model(rf_spec)

8.2 Почему модель путает Эмили Бронте

Эмили Бронте — единственный автор с одним романом, поэтому при проверке «один роман отложен» «Грозовой перевал» полностью уходит в тест, и обучить модель на ее стиле не на чем. Чтобы понять, к кому модель отнесет роман в этой ситуации, я построила дерево сходства авторов. Расстояния считаются по 200 MFW в духе дельты Берроуза: частоты усредняются по автору, переводятся в z-оценки, и берется манхэттенское расстояние. Иерархическая кластеризация по этой матрице показывает, какие авторы стилистически ближе всего друг к другу.

Код 
plot(author_tree, hang = -1, main = "Сходство авторов по стилю",
     xlab = "", ylab = "Расстояние (дельта Берроуза)", sub = "")

На дереве три сестры Бронте (AB, CB, EB) образуют единый кластер: их стили заметно ближе друг к другу, чем к любому другому автору. Эмили примыкает к Шарлотте — поэтому именно к ней модель и относит «Грозовой перевал», когда не видела ни одного фрагмента Эмили в обучении. Это не ошибка модели, а прямое следствие стилистического родства сестер: атрибутировать класс, у которого нет ни одного обучающего примера, в принципе невозможно.

9 Выводы

Лучшая модель — мультиномиальная регрессия на 200 MFW и структурных признаках. Она достигает CV-accuracy около 95% при честной группировке по книге, и верно атрибутирует 26 из 27 романов.

Линейная модель опередила Random Forest примерно на 15 процентных пунктов. На стандартизированных частотах служебных слов признаки почти линейно разделимы, и регуляризованный логит работает оптимально, тогда как лес дробит диапазон на пороги и теряет масштабную информацию.

Значимые предикторы интерпретируемы. Стерн опознается по рекордной плотности тире. Остин — по словам свободно-косвенного дискурса (every, could, must, herself). Ричардсон — по letter, dear и высокой плотности запятой, что прямо вытекает из эпистолярной формы. Диккенс, Теккерей и Троллоп — по длинным предложениям и обилию точек с запятой.

Главное ограничение — Эмили Бронте. При проверке «один роман отложен» «Грозовой перевал» неминуемо приписывается Шарлотте Бронте. Модель не видела ни одного чанка Эмили в обучении, а работы сестер Бронте стилистически близки, что подтверждает и дерево сходства авторов.

Стратификация по чанкам дает почти 100% точности, но в тест попадали чанки обучающей выборки. Групповая кросс-валидация снизила оценку примерно на 5 процентных пункта.

# Предобработка текстов

Тексты нужно очистить от шапок (заглавие/`BY`/имя автора/`VOLUME`/`CHAPTER`) и концевые маркеры (`THE END`).

Лемматизацию и стемминг я не делаю специально. Атрибуция авторства
опирается на частоты служебных слов в их исходных формах, и
нормализация словоформ только стерла бы авторский сигнал.

```{r clean-display}
#| eval: false
clean_one <- \(path) {
  raw <- readr::read_file(path)

  # Удаляю концевые маркеры только в самом конце, чтобы не зацепить
  # упоминания "the end" внутри прозы
  tail_chunk <- substr(raw, max(1, nchar(raw) - 500), nchar(raw))
  m <- regexpr("\\b(FINIS|THE END|End of the (Fourth|Fifth|Sixth|Project Gutenberg).*)\\b",
               tail_chunk, ignore.case = TRUE)
  if (m > 0) {
    cut_at <- nchar(raw) - 500 + m
    raw <- substr(raw, 1, cut_at - 1)
  }

  # Удаляю первые короткие строки шапки
  lines <- strsplit(raw, "\r?\n")[[1]]
  header_re <- "^\\s*(by|volume|chapter|book|preface|to the|dedication|a work by|nine volumes|one of|history)\\b"
  body_start <- 1L
  for (i in seq_len(min(25, length(lines)))) {
    L <- str_trim(lines[i])
    if (L == "") next
    if (nchar(L) < 40 && (toupper(L) == L || grepl(header_re, L, ignore.case = TRUE))) {
      body_start <- i + 1L; next
    }
    break
  }
  paste(lines[body_start:length(lines)], collapse = "\n")
}
```

# Инжиниринг признаков

Я построила две группы признаков:

1. **MFW (200 самых частотных слов корпуса)** — нормализованные
   частоты.
2. **Структурные признаки** — средняя длина слова, средняя длина
   предложения, TTR, индекс Оноре, плотности
   запятой, точки с запятой, тире, восклицательных и вопросительных
   знаков.

Структурные признаки считаются на тех же чанках, что и MFW.

Частоты частей речи я не добавляла, чтобы не утяжелять пайплайн
разбором через `udpipe`. 200 MFW и структурные метрики дают
достаточный набор признаков для атрибуции.

```{r features-display}
#| eval: false
MFW_N <- 200

# MFW
dfm_full  <- dfm(toks_chunks)
top_terms <- names(topfeatures(dfm_full, n = MFW_N))
dfm_mfw   <- dfm_full |>
  dfm_select(pattern = top_terms, selection = "keep") |>
  dfm_weight(scheme = "prop")
mfw_df <- dfm_mfw |>
  convert(to = "data.frame") |>
  as_tibble() |>
  rename_with(\(x) paste0("mfw_", x), -doc_id)

# Структурные признаки на тех же чанках
honore_r <- \(tw) {
  N <- length(tw); if (N == 0) return(NA_real_)
  tab <- table(tw); V <- length(tab); V1 <- sum(tab == 1)
  if (V1 == V) return(NA_real_)
  100 * log(N) / (1 - V1 / V)
}

chunk_substrings <- character(nrow(chunk_meta))
names(chunk_substrings) <- chunk_meta$doc_id

for (bk in unique(chunk_meta$book_id)) {
  text_raw <- texts$text[texts$file == bk]
  pos <- gregexpr("[A-Za-z][A-Za-z']*", text_raw, perl = TRUE)[[1]]
  match_lens <- attr(pos, "match.length")
  bk_chunks <- filter(chunk_meta, book_id == bk)
  for (i in seq_len(nrow(bk_chunks))) {
    chunk_n <- bk_chunks$n_tokens[i]
    word_start <- (i - 1) * CHUNK_SIZE + 1
    word_end   <- word_start + chunk_n - 1
    if (word_end > length(pos)) word_end <- length(pos)
    char_start <- pos[word_start]
    char_end   <- pos[word_end] + match_lens[word_end] - 1
    chunk_substrings[bk_chunks$doc_id[i]] <- substr(text_raw, char_start, char_end)
  }
}

struct_df <- tibble(
  doc_id  = chunk_meta$doc_id,
  mean_word_len = sapply(as.list(toks_chunks), \(w) mean(nchar(w))),
  ttr = sapply(as.list(toks_chunks), \(w) length(unique(w)) / length(w)),
  honore_r  = sapply(as.list(toks_chunks), honore_r),
  mean_sent_len = sapply(chunk_substrings[chunk_meta$doc_id], \(t) {
                    n_sent <- max(1, length(strsplit(t, "[.!?]+")[[1]]))
                    n_word <- length(strsplit(t, "\\s+")[[1]])
                    n_word / n_sent
                  }),
  comma_rate  = sapply(chunk_substrings[chunk_meta$doc_id],
                         \(t) 1000 * str_count(t, ",")  / nchar(t)),
  semicolon_rate = sapply(chunk_substrings[chunk_meta$doc_id],
                         \(t) 1000 * str_count(t, ";")  / nchar(t)),
  dash_rate = sapply(chunk_substrings[chunk_meta$doc_id],
                         \(t) 1000 * str_count(t, "--") / nchar(t)),
  question_rate = sapply(chunk_substrings[chunk_meta$doc_id],
                         \(t) 1000 * str_count(t, stringr::fixed("?")) / nchar(t)),
  excl_rate = sapply(chunk_substrings[chunk_meta$doc_id],
                         \(t) 1000 * str_count(t, stringr::fixed("!")) / nchar(t))
)

features <- chunk_meta |>
  left_join(mfw_df, by = "doc_id") |>
```

```{r recipe-display}

rec <- recipe(authorID ~ ., data = train_chunks) |>
  update_role(doc_id, book_id, author, n_tokens, new_role = "ID") |>
  step_zv(all_predictors()) |>
  step_normalize(all_numeric_predictors())

# Модель 1: мультиномиальная регрессия с L1/L2
multinom_spec <- multinom_reg(penalty = tune(), mixture = tune()) |>
  set_engine("glmnet") |>
  set_mode("classification")

# Модель 2: случайный лес
rf_spec <- rand_forest(trees = 500, mtry = tune(), min_n = tune()) |>
  set_engine("ranger", importance = "impurity") |>
  set_mode("classification")

wf_multinom <- workflow() |> 
  add_recipe(rec) |> 
  add_model(multinom_spec)
wf_rf <- workflow() |> 
  add_recipe(rec) |> 
  add_model(rf_spec)
```

## Почему модель путает Эмили Бронте

Эмили Бронте — единственный автор с одним романом, поэтому при
проверке «один роман отложен» «Грозовой перевал» полностью уходит в
тест, и обучить модель на ее стиле не на чем. Чтобы понять, к кому
модель отнесет роман в этой ситуации, я построила дерево сходства
авторов. Расстояния считаются по 200 MFW в духе дельты Берроуза:
частоты усредняются по автору, переводятся в z-оценки, и берется
манхэттенское расстояние. Иерархическая кластеризация по этой
матрице показывает, какие авторы стилистически ближе всего друг к
другу.

```{r}
#| label: fig-tree
#| fig-cap: "Дерево сходства авторов по 200 MFW (дельта Берроуза)"
#| fig-height: 5

     xlab = "", ylab = "Расстояние (дельта Берроуза)", sub = "")
```

На дереве три сестры Бронте (`AB`, `CB`, `EB`) образуют единый
кластер: их стили заметно ближе друг к другу, чем к любому другому
автору. Эмили примыкает к Шарлотте — поэтому именно к ней модель и
относит «Грозовой перевал», когда не видела ни одного фрагмента
Эмили в обучении. Это не ошибка модели, а прямое следствие
стилистического родства сестер: атрибутировать класс, у которого нет
ни одного обучающего примера, в принципе невозможно.

# Выводы

Лучшая модель — мультиномиальная регрессия на
200 MFW и структурных признаках. Она достигает CV-accuracy около 95% при
честной группировке по книге, и верно атрибутирует 26 из 27 романов.

**Линейная модель опередила Random Forest** примерно на 15 процентных пунктов. На стандартизированных частотах служебных слов признаки почти линейно разделимы, и регуляризованный логит работает оптимально, тогда как лес дробит диапазон на пороги и теряет масштабную информацию.

**Значимые предикторы интерпретируемы.** Стерн опознается по рекордной
плотности тире. Остин — по словам свободно-косвенного дискурса
(`every`, `could`, `must`, `herself`). Ричардсон — по `letter`, `dear`
и высокой плотности запятой, что прямо вытекает из эпистолярной формы.
Диккенс, Теккерей и Троллоп — по длинным предложениям и обилию точек с
запятой.

Главное ограничение — Эмили Бронте. При проверке «один роман
отложен» «Грозовой перевал» неминуемо приписывается Шарлотте Бронте.
Модель не видела ни одного чанка Эмили в обучении, а работы сестер Бронте
стилистически близки, что подтверждает и дерево сходства авторов.

Стратификация по чанкам дает почти 100% точности, но в тест попадали чанки обучающей выборки.
Групповая кросс-валидация снизила оценку примерно на 5 процентных пункта.

## Что можно улучшить дальше

Анализ можно расширить. Имеет смысл добавить дельту Берроуза как
отдельную модель-бейзлайн, подключить частоты частей речи и
символьные триграммы — известно, что эти признаки часто улучшают
качество стилометрической атрибуции.
